# C950 - Data Structures and Algorithms II 
Data Structures and Algorithms II explores the analysis and implementation of high-performance data
structures and supporting algorithms, including graphs, hashing, self-adjusting data structures, set representations, and dynamic programming. The
course also introduces students to NP-complete problems. The course discusses how to use Python techniques to implement software solutions for
problems of memory management and data compression. 

## Tasks 
Developed a Python-based package delivery routing system using a greedy nearest-neighbor algorithm.

Algorithm Overview:
- Identification of algorithm and data structures used
- Analysis of space and time complexities of functions
- Analysis of the solution's scalability and adaptability
- Analysis of the solution's efficiency and maintainability
